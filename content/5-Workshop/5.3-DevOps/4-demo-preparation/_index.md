# Demo Preparation

The demo should show real inputs, actions, outputs, and evidence.

Recommended order:

1. Introduce the problem.
2. Present the architecture.
3. Run the simulator.
4. Verify IoT messages.
5. Verify Firehose and S3 Raw.
6. Run data processing.
7. Present SageMaker training and forecast.
8. Test the backend API.
9. Trigger an SNS alert.
10. Present monitoring and budget controls.
